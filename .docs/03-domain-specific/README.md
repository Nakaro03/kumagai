# ドメイン固有の知識（Domain-Specific Knowledge）

このディレクトリには、技術トレンド予測研究プロジェクト固有の知識を格納しています。

**カテゴリID**: `03-domain-specific`
**更新頻度**: 高頻度（新しい実験結果が出るたび）
**参照優先度**: 高（新しい予測ターゲット・アーキテクチャを検討する際は必読）

## ファイル一覧

| 用途 | ファイル | 内容 |
| --- | --- | --- |
| 新しい実験を始める前に必ず読む | [研究の規律](research-discipline.md) | 訓練不要天井を先に測る・事前登録ゲート・holdout+多seedの規律 |
| 「これは既に試された方向か」を確認する | [プロジェクトマップ](project-map.md) | タスク族(WHERE/HOW-MUCH/WHEN/WHAT-NEW/EXIT)ごとの到達点、主要文書へのポインタ |
| データの前提を確認する | [データとドメイン](data-and-domains.md) | ドメイン一覧、CPC/IPC粒度、既知のデータ品質上の注意点 |

## 参照方法

**新しい予測ターゲット・アーキテクチャのアイデアが浮かんだら、実装前に必ず[プロジェクトマップ](project-map.md)で「既に試されていないか」を確認すること。** 本プロジェクトでは、一見新しいアイデアが実は既存の検証結果の焼き直しだったケースが複数回発生している。
