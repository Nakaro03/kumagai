# 研究の規律（Research Discipline）

## 誠実性の原則

- すべての精度主張は **holdout + ≥3〜5 seed（できれば10 seed）+ 対応あり検定** で行う（単一seedの好結果はseed運の可能性が高い——本プロジェクトでは実際に「+126%」という初期の好結果が、後にtransductiveアーティファクトだったと判明し撤回された実績がある）
- 学習モデルの増分は必ず**訓練不要天井との差分**で報告する（見かけの精度・AUCだけを主張しない）
- 否定的結果は「弱かった」ではなく「何と同着だったか」まで特定する

## 新しいターゲット変数・アーキテクチャを試す前の手順（Gate 0）

1. **訓練不要ベースラインを先に測る**: 人気度、関連性（構造的近接度）、momentum、streak/持続性など、ドメインに応じた素朴な指標のAUC/PR-liftを、ニューラルモデルを一切書く前に測定する
2. **停止規則を事前登録する**: 「どのベースラインもAUC≥X または PR-lift≥Y を一貫してクリアしなければ投資しない」という基準を、結果を見る前に文書化する
3. **クリアした場合のみ次の投資判断**（Gate S: 線形モデルとの比較 → Gate L: ニューラルモデルとの比較、という段階を踏む）

この規律は、本プロジェクトで実際に機能した——[Exit Hazard](https://github.com/Nakaro03/kumagai/issues/2)は、この手順を踏んだ結果、プロジェクト初めて事前登録した停止規則を通過した正の発見になった。

## 「Simple beats complex」パターンへの向き合い方

このプロジェクトでは、参入予測・成長率予測・タイミング予測・新規結合予測のいずれも、静的ベースライン（人気度・関連性・momentum・構造的近接度）が学習モデル（RNN, Neural ODE, PNODE, Dual-Force, TAP-NODE, Neural Jump-ODE点過程）を上回るという結果が10回近く独立に再現している。

**これは失敗ではなく、診断的価値を持つ結果として扱う**:

- velocity attribution（6ドメイン力場診断）は、力場が説明する分散がR²≈0.01〜0.05にとどまることを示している。データ生成過程が連続的drift（Neural ODEが得意とする対象）ではなく、離散的・関連性ゲート付き参入だからだと解釈できる
- 新しいアーキテクチャを試す前に、「このタスクの生成過程は本当に連続力学か、離散イベントか」を先に検討する。離散イベントであれば、点過程（temporal point process / Neural Jump-ODE）が構造的には正しい枠組みだが、**構造が正しいことと精度が出ることは別**（本プロジェクトのArch B, `techtrend_arch_b.py`はこの正しい構造を持ちながら失敗した）

## 何が実際にうまくいったか（このプロジェクトの成功パターン）

1. **記述的・可視化ツール**（"honest tool"路線）: X3-clean（勾配流可視化）、TAP-NODEの可視化的価値、conformal較正の転移性——予測精度を主張せず、不確実性を正直に示すツールとして価値を持つ
2. **訓練不要スコアそのものが成果物**: Exit Hazard（persistence/streakシグナル）——ニューラルモデルへの投資が正当化されないほど、素朴な特徴量だけで頑健な信号が出た事例
3. **測定・データ品質研究**（新しいジャンル）: 重複出願検出の妥当性検証（`kumagai-patent-analysis` issue #11）——予測ではなく測定バイアスの定量化という、このプロジェクトの主戦場とは異なる貢献の型

## 避けるべきパターン

- 同じ「連続的な移動・速度が予測シグナルを持つ」という枠組みを、対象（企業→発明者、CPC→CPC-CPCペア等）だけ変えて再提案すること。過去4回、これで「既に試された/失敗する」という結論に至っている
- 便宜的サンプル（最大・最も極端なケースだけ）での検証を「母集団の代表値」として報告すること（層化・無作為抽出を徹底する）
- transductive評価（テストラベルに触れる自由パラメータでの学習）をinductive評価と混同すること
