## 1. 何を解こうとしているか

**問い**: 「**ある企業は、次にどの技術分野に参入するか?**」

具体例:
> Nabors Drilling Technologies USA は、2015 年時点で 13 個の掘削技術（E21B 系）に特許を持っている。**今後 3 年で新たにどの技術に出願するか?**

このシステムは、上の問いに対し:
- **較正された確率付きランキング**を返す（例: "E21B36 を 50% の確率で参入"）
- **2D 地図**で「予測が信頼できるゾーン vs できないゾーン」を可視化
- **15 年の業界動向アニメーション**で文脈を提供

---

## 2. なぜ難しいか — proximity-bound 限界

10 個以上のアーキテクチャ（Neural SDE、GNN、Transformer、TSFM 等）を試した結果:

> **複雑な ML 手法は、単純な「関連性指標 (Adamic-Adar)」を超えない。**

これは "**proximity-bound（近接性に束縛される）**" と我々が名付けた現象です:

| 予測対象 | 結果 |
|---|---|
| 関連した技術への拡張（例: 掘削 → 別の掘削サブ群）| **予測可能**（P@5 = 14× base rate）|
| 真の新規・破壊的参入（例: 掘削 → AI 半導体）| **偶然レベル**（AUC ≈ 0.50）|

→ つまり「**簡単な部分は当たる、難しい部分は誰がやっても当たらない**」が確定的に証明された。

## 3. 主要な概念（3 つ）

### 概念 1: **関連性 (Adamic-Adar)**

```
score(企業 f, 候補技術 g) = Σ_{j ∈ 企業の保有技術} 共起頻度(g, j) / log(次数(j))
```

「**自社が今やっている技術と "共起した" 技術ほど、参入確率が高い**」という古典指標。1958 年から知られている。本プロジェクトの中心信号。

### 概念 2: **較正 (Calibration)**

```
raw スコア → Isotonic Regression → honest な確率
```

「**13% と予測したら、本当に 13% で実現する**」を保証する処理。ECE = 0.001（ほぼ完全）。
これにより推薦の信頼度がそのまま意思決定に使える。

### 概念 3: **予測可能性境界**

```
2D 潜在空間上で:
  🟢 緑ゾーン  = 推薦が信頼できる領域
  🔴 赤ゾーン  = 偶然と区別不能（proximity-bound）
```

地図上に**信頼してよい/しない技術領域**を視覚的に区別する。これが研究の独自貢献。

## 4. 入力と出力の概要

### 入力

| データ | 形式 | 用途 |
|---|---|---|
| 企業 × CPC × 出願日 | CSV | 二部グラフ構築 |
| 特許タイトル文（補助）| 大規模 TSV | 意味埋め込み |
| 企業名対応表 | CSV | ケーススタディの可読化 |

### 出力

1. **推薦テーブル**（CSV/JSON）— 各企業の Top-K 候補 + 較正信頼度 + 実際の参入 ✓/✗
2. **可視化群** — 統合図、トレンドアニメ、比較グラフ等
3. **集計メトリクス** — AUC、P@K、Lift、ECE

## 5. ユースケース

### A. R&D ポートフォリオ戦略
「自社が次に投資すべき隣接技術」を、honest 信頼度付きで提案。

### B. 業界トレンド把握
「過去 15 年、技術空間はどう動いたか」を 10 秒の GIF で説明。

### C. 競合インテリジェンス
特定の競合企業のポートフォリオから、次の動きを予測。

### D. 学術研究
「予測の限界を定量的に明らかにする限界論文」として publish 可能。

---

## 6. 何ができないか（honest に）

- ❌ **破壊的新技術（真の飛躍）の予測** — proximity-bound で本質的に不可
- ❌ **個別出願の正確な日付予測** — タイミングは別問題
- ❌ **市場価値・収益性予測** — 特許出願≠商業的成功
