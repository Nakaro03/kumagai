## 2. 図に出てくる「共通記号」一覧

すべての地図系可視化で共通:

| 記号 | 意味 |
|---|---|
| **★（黒星、大）** | 選択した企業のポートフォリオ位置 |
| **★（金星、中）** | Sweet Spot（hot × predictable な技術） |
| **🟢 緑の丸** | 推薦上位 + 実際に参入した（HIT） |
| **🔴 赤の丸** | 推薦上位 + 入らなかった（MISS） |
| **緑/赤の矢印** | 企業の重心から推薦技術への矢印 |
| **🟢 緑の背景** | 予測可能ゾーン（推薦が当たる）|
| **⚪ 白の背景** | proximity-bound ゾーン（偶然）|
| **黒の破線** | 予測可能性の境界（2× base rate）|
| **数字 ①②③** | Top-K 推薦の順位 |

→ **覚えるべきは ★ と 緑/赤、それと黒破線 だけ**

## 3. 各図の詳細な読み方

### 図 A: **viz_predictability_map_v3.png**（最もシンプル）

**何が描かれているか**:
- 左側の大きな地図 + 右側の表

**地図の読み方**:
```
背景の色: 緑が濃い = 推薦が当たりやすい
        : 白に近い = 偶然と区別できない
        
ゾーンラベル (E04, E21, E02 等) = 技術カテゴリ
  E04 = 建築構造
  E21 = 掘削
  E02 = 水利工事

黒い ★ = 例企業（中国石油大学）のポートフォリオ
番号付き丸 (1-5) = この企業へのおすすめ Top-5
  ✓緑 = 実際に 3 年内に参入した
  ✗赤 = 入らなかった
```

**右側の表**:
```
# | CPC      | conf  | hit
1 | E21B36   | 27.5% |  ✓   ← "27.5% は較正済み、本当に 27.5% で当たる"
2 | E21B47   | 26.4% |  ✓
3 | E21B41   | 22.8% |  ✓
4 | E21B19   | 22.6% |  ✗
5 | E21B34   | 22.0% |  ✓
Hits in top-5: 4/5  ← 5 件中 4 件的中
```

**何がわかるか**:
- ✅ 集中型企業（掘削に特化）の隣接拡張は当たる（4/5 hit）
- ✅ 信頼度 22-28% は base rate (1.2%) の **20 倍**
- ✅ 全推薦が緑ゾーンに収まる = 信頼できる予測

### 図 B: **viz_final_integrated.png**（メイン統合図）

**2 パネル + 表**で構成。

**パネル (a) "Hot vs Cold"**:
```
バブルサイズ = その技術の活動度（出願企業数）
バブル色 = トレンド方向
  🔴 赤 = ここ 5 年で活発化
  🔵 青 = 冷却中
  ⚪ 白 = 横ばい
ラベル付き = 注目度トップ
```

**パネル (b) "Predictability"**:
```
緑背景 = 予測可能ゾーン
黒破線 = 予測可能性の境界
★金 (gold star) = Sweet Spot（hot AND predictable）
★黒 = 企業のポートフォリオ
矢印 = 推薦（緑=的中、赤=外し）
```

**右側の表**:
- 企業情報、Top-5 推薦、Sweet Spot 一覧、較正注記

**読み方の流れ**:
1. (a) で「どの技術領域が今熱いか」を見る
2. (b) で「自社のポジション + 推薦先」を見る
3. ★金（Sweet Spot）が「**最も賢い投資先**」

---

### 図 C: **viz_trends_animation.gif**（時間アニメ）

**1 フレーム = 1 年**（2001-2020 の 20 フレーム）

```
右上の大きな数字 = 表示中の年
バブルサイズ = その年の活動度
バブル色 = 5 年前との比（赤=加速、青=減速）
ラベル付き = その年のトップ 5 技術
```

**見るべきポイント**:
1. **どこから赤いバブルが生まれるか**: 新興技術の発生地点
2. **赤が青に変わる時期**: 技術が成熟・冷却するタイミング
3. **大きさの変化**: 活動度の絶対増減

**例**: GIF を見ると、2010 年代に E04F（床仕上げ）系が大きく成長することがわかる。

---

### 図 D: **compare_prediction_accuracy.png**（棒グラフ）

**3 パネル横並び**: AUC / P@5 / Lift@5 を 7 手法で比較

```
横軸 = 手法
縦軸 = スコア（高いほど良い）

赤の点線 = chance/base rate
緑のバー = Adamic-Adar（通常勝者）
赤のバー = Fusion LR（同等）
暗赤のバー = Fusion + 較正（同等 + 信頼度 honest）
```

**読み方**:
- **Random** (灰)が下限
- **AA** (緑)がトップ
- 複雑手法 (Content, Human-aware) は AA に負ける
- **同色高さ ≒ 「複雑にしても勝てない」が一目**

---

### 図 E: **viz_line_forecast_backtest.png**（折れ線予測）

**8 サブパネル + ボックスプロット + 散布図**

各サブパネル:
```
青の実線 = 過去の活動度（2001-2015）
青の破線 = 実際の "未来" データ（2016-2018）
灰/赤/緑の線 = 3 手法の予測

ラベル "best MAPE = 0.02" = 最良予測誤差 2%
```

**ボックスプロット** (下段左): 145 CPC での MAPE 分布
**散布図** (下段右): 活動度 vs 予測しやすさ

**何がわかるか**:
- ✅ 集約活動度は予測可能（中央値 MAPE 21%）
- ✅ 活動が多い CPC ほど予測しやすい
- ✅ Linear と Holt-Winters が同等 = シンプルで OK

## 4. 「色の意味」一覧（再掲・重要）

### 背景色系（予測可能性）
| 色 | 意味 |
|---|---|
| 🟢 緑 | 推薦が当たる領域（信頼可）|
| 🟡 黄緑 | 中間 |
| ⚪ 白 | 予測できない（proximity-bound）|

### バブル色系（トレンド方向）
| 色 | 意味 |
|---|---|
| 🔴 赤 | 加熱中（rising）|
| 🟠 オレンジ | やや加熱 |
| 🟡 黄 | 横ばい |
| 🔵 青 | 冷却中（declining）|

### 矢印・記号色系
| 色 | 意味 |
|---|---|
| 緑 (#138D75) | 推薦の **的中**（HIT）|
| 赤 (#B03A2E) | 推薦の **外し**（MISS）|
| 紺 (#1F4E79) | 過去フロー |
| 暗赤 (#D62728) | 予測フロー |

## 5. ありがちな誤読

### ❌ よくある誤読 1
「**赤いバブル = 危険**」

→ 正しくは「**赤 = 加熱中（chance/opportunity）**」。投資先として注目すべき領域。

### ❌ よくある誤読 2
「**緑のバブル = 注目度高い**」

→ バブル色は**トレンド方向**、サイズが**現在の活動度**（注目度）。混同しないこと。

### ❌ よくある誤読 3
「**地図上の距離 = 物理的・意味的距離**」

→ UMAP 投影なので**近いところは似た技術**ではあるが、**距離の絶対値には意味がない**。隣接していれば近い、離れていれば遠い、程度の判断にとどめる。

### ❌ よくある誤読 4
「**信頼度 50% は半々の確率**」

→ 較正後は実際 50% で当たる。**1 件あたりの確率**であり、Top-5 全部当たるとは別。

## 7. プレゼン用 1 セット（おすすめ）

5 分のプレゼンで使う 3 枚:

1. **viz_trends_animation.gif** — 業界の流れを 10 秒で
2. **viz_final_integrated.png** — 推薦エンジンの価値を提示
3. **compare_prediction_accuracy.png** — 単純が複雑に勝つ証拠

15 分のプレゼンならこれに:

4. **viz_predictability_map_v3.png** — 具体的な企業例
5. **viz_line_forecast_backtest.png** — 集約予測の正しさ

## 8. それでも「わかりにくい」場合の対処

可視化はどうしても情報量が多いので、**「何が分かれば OK か」を 1 つに絞って**見ると良いです:

| 知りたいこと | 図のどこを見るか |
|---|---|
| 「自社は次にどこに動くべき?」 | **viz_final_integrated.png** の右パネル Top-5 推薦 |
| 「業界全体は今後どこに動く?」 | **viz_trends_animation.gif** の最後の数フレーム |
| 「複雑モデルは必要か?」 | **compare_prediction_accuracy.png** の P@5 棒の高さ |
| 「推薦の信頼度は honest か?」 | **viz_final_integrated.png** 右の "calibrated" 注記 |
